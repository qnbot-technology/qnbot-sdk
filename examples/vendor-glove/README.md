# 厂商手套协议示例

本示例先调用 `start()` 打开显式串口并开始接收，再查询设备信息、当前订阅表与输出模式，订阅读取 10 个原始传感器样本并检查 SDK 样本序号前进，最后调用 `stop()` 释放串口并关闭 SDK。

使用本 PR 的匹配 Core/native 构建，首个发布版本尚未确定。无需安装算法包。设备必须连接可访问的串口，并已配置为主动上报模式且订阅所需组件。示例只读，不修改设备参数或校时。

- [Python：安装与运行](python/README.md)
- [C++：构建与运行](cpp/README.md)

准备实际串口路径和设备手侧。两种语言均接受 `--port`、`--side left|right` 和可选的 `--baudrate`（默认 115200）。两者均输出查询状态、原始 TLV 值、样本序号、协议序号、位图、设备时间戳和各块字节数。

10 秒内未收到 10 帧时，检查当前模式、订阅表和串口连接。组件未装备或未订阅时不会出现相应块。设备时间戳可重复，协议序号可回绕；SDK 样本序号应持续前进。原始块不等于骨架或标定结果，EMF 数据不在示例中解码。
